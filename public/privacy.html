Privacy and optional analytics

Crayon Breath works without analytics. If you opt in, we store first-party product analytics to improve game flow and reliability.

Analytics can include chosen display name, random browser identifier, random session identifier, browser language and timezone, coarse country or region supplied by a trusted edge proxy, game mode, waiting and game outcomes, configured and completed rounds, and server performance.

When owner enables game-start notifications, an ntfy service receives only aggregate game mode, participant count, and configured rounds. Notifications never include display names, location, raw IP addresses, room codes, browser identifiers, chat, tokens, or drawings.

Display names are not verified identities. Location is approximate, may be wrong because of VPNs or network routing, and can be unknown. We do not request GPS, store raw IP addresses, fingerprint devices, store chat, guessed words, drawing strokes, or full URLs.

Data stays on Crayon Breath infrastructure for up to 90 days, then rotates. Analytics failure never affects play. Contact site owner to request deletion of analytics linked to a display name; names can be shared, so deletion may require extra information.

Do not enter personal information as your display name. Children should ask a parent or guardian before opting in. This notice may change before advertising or third-party analytics starts.
